# The pages against the build

The inventory of session 1.1 of [the roadmap](../ref/ROADMAP.md). Every statement a page makes
about the build, the layout of `source/` or the output is listed with a verdict, checked on
2026-09-30 at `develop` `2bcbd96` by reading `build/` and by running the commands.

- **true**: the build does it.
- **false, build**: the page is right and the build is fixed in session 1.2.
- **false, page**: the build is right and the page is corrected in session 1.3.
- **decision**: both are defensible; the decision named in the roadmap settles it.

This document is temporary and is deleted at the end of Phase 1. What it establishes moves
into `docs/architecture.md`, the roadmap's findings and the pages.

## Contradictions with a recommendation of the roadmap

None. D4 to D8 hold as recommended. Two new decisions came out of the inventory:

- **D14**, WebP on Android. The design-guidelines page recommends WebP for Android and the
  build drops it. Including it adds files to `dist/android/` of the default build, so the
  maintainer decides. Until then the build keeps dropping it and session 1.3 corrects the
  table.
- **D15**, PNG under `icons/` for iOS and Android. The design-guidelines page lists PNG icons
  as an alternative for both and the icons page says every file is distributed; the build drops
  a PNG under `icons/` for both. No such file exists in `source/`, so adding `.png` to the two
  icon filters changes no output today. Taken by the plan: session 1.2 adds it.
