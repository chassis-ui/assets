# ⚙️ Lightweight Income Roadmap for Chassis

| Stage                        | Timeline    | Focus                                 | Income Channels                            | Effort Level   |

| **1. Setup & Awareness**     | 0–2 months  | Build visibility, polish repo         | GitHub Sponsors, Tip Jar, Organic leads    | 🔹 Low         |

---

## ✅ STAGE 1: Setup & Awareness (Now → Month 2)

**Goal**: Make Chassis look legit and worth following
**Actions**:

* Launch clean repo(s) + readme + logo + minimal landing page
* Add GitHub Sponsors or Ko-fi links
* Share behind-the-scenes: “Building an open-source DS framework solo”
* List yourself on [opencollective.com](https://opencollective.com/), [github.com/sponsors](https://github.com/sponsors), [liberapay.com](https://liberapay.com/)

**Income Sources**:

* GitHub Sponsors (\$10–50/mo from early adopters)
* 1–2 “can you help us” consulting leads

---

## 🔸 STAGE 2: Authority & Utility (Month 2 → Month 5)

**Goal**: Provide value *around* the repo
**Actions**:

* Publish:

  * “How to set up a multi-platform design system with tokens”
  * “Cross-functional team alignment with Chassis”
* Release:

  * A free or low-cost **token starter kit** (tokens + Figma)
  * A 30–60 minute **mini video course** on Gumroad or Lemon Squeezy

**Income Sources**:

* Paid starter kits (\$9–29)
* Mini course sales (\$29–59)
* Small team consulting (setup, audits) — 2–3 clients at €500–1,000 each

---

## 🔶 STAGE 3: Productized Services (Month 5 → 12)

**Goal**: Turn consulting into packages
**Actions**:

* Offer a “Chassis Setup Package”:

  * 2–3 day setup for teams (Figma sync, tokens, CSS)
  * Flat-rate pricing (e.g., €750–1,500)
* Create team workshops (live or async)
* Write a free whitepaper: “Scaling Design Systems Across Brands” → leads

**Income Sources**:

* Flat-fee services for early adopters
* Pay-what-you-want team workshops
* Book or full course (\$79–199)

---

## 🟣 STAGE 4: Monetizable Ecosystem (Month 12+)

**Goal**: Build premium tooling *on top of* Chassis
**Actions**:

* Figma Plugin (sync with Chassis tokens or docs)
* Live playground builder (based on Chassis tokens → CSS → UI preview)
* CLI tool (like create-chassis-app or a config manager)

**Income Sources**:

* Plugin license (\$10–50 per org/mo)
* Hosted SaaS (\$9–99/mo depending on team size)
* Donations & grants
