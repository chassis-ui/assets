# Documentation Organization

This directory contains project documentation organized by purpose:

## 📁 Structure

```
docs/
├── planning/           # Project planning and architecture
│   ├── multi-repo.md   # Multi-repository architecture specification
│   └── project.md      # Original project documentation
├── development/        # Development process documentation  
│   └── DEVELOPMENT_LOG.md # Development log and progress tracking
└── knowledge/          # Knowledge exports and system documentation
    ├── CHASSIS_KNOWLEDGE_EXPORT.md # Comprehensive knowledge export
    └── CHASSIS_SYSTEM_KNOWLEDGE.md # System knowledge documentation
```

## 📋 Purpose

### Planning Documents (`planning/`)
- **Architecture decisions** and multi-repo structure
- **Project specifications** and requirements
- **Strategic planning** documentation

### Development Documents (`development/`)
- **Development logs** and progress tracking
- **Build processes** and workflow documentation
- **Issue tracking** and resolution notes

### Knowledge Base (`knowledge/`)
- **System exports** and comprehensive documentation
- **Technical knowledge** preservation
- **Architecture understanding** for future reference

## 🔄 Maintenance

These documents are kept for:
- Historical reference
- Architecture understanding
- Knowledge transfer
- Future planning and development

They can be safely moved or archived once no longer needed for active reference.
